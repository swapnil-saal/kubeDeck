# Keyboard shortcuts

KubeDeck has a few app-wide shortcuts and a handful more inside the kubectl palette, the log viewer and Ask Deck. On macOS use **⌘**; on Windows and Linux use **Ctrl** where this page shows ⌘. **Settings → About** lists the app-wide ones.

## Everywhere

| Keys | Action |
|---|---|
| **⌘K** | Open or close the [kubectl palette](/guide/kubectl-palette) |
| **⌘B** | Collapse or expand the sidebar |

## kubectl palette

| Keys | Action |
|---|---|
| **↑** / **↓** | Move through the suggested commands |
| **⌘Enter** | Run the selected command |
| **Enter** (in a command box) | Run that command. Not for interactive commands such as `exec` |
| **Shift+Enter** (in a command box) | New line |
| **Esc** | Close the command output; press again to close the palette |

## Logs

| Keys | Action |
|---|---|
| **Enter** (in the filter box) | Jump to the next match |
| **Shift+Enter** (in the filter box) | Jump to the previous match |
| **Esc** (in the filter box) | Clear the filter |
| **Esc** | Leave focus mode |

See [Logs](/guide/logs).

## Ask Deck

| Keys | Action |
|---|---|
| **Enter** | Send your message |
| **Shift+Enter** | New line |
| **Esc** | Close the conversation history drawer |
| **←** / **→**, **↑** / **↓**, **Home**, **End** | Move between the steps of an answer when a step has focus |

See [Ask Deck](/guide/assistant).
